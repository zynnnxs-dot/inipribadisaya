# ECObike

Simulasi pemesanan sepeda listrik ECObike (depot Bintaro Jaya). Situs statis satu halaman, tanpa build.

## Deploy ke Vercel
1. Upload folder ini ke GitHub.
2. Di Vercel, pilih Add New > Project, lalu import repo-nya.
3. Framework Preset: Other. Kosongkan Build Command dan Output Directory, lalu Deploy.
