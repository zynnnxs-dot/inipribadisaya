# NDREXAN — Personal Portfolio

Website portofolio Andre Arshavin dengan HTML, CSS, dan JavaScript biasa. Tampilan editorial putih-hitam, intro cinematic, galeri karya, project website, dan panel admin Supabase.

## Deploy ke Vercel
1. Ekstrak ZIP ini.
2. Upload **semua isi ZIP langsung ke root repository GitHub** (jangan upload folder pembungkus).
3. Di Vercel, import repository tersebut. Framework Preset: Other; Build Command dan Output Directory dikosongkan.
4. Deploy.

Untuk setup admin dan Supabase, ikuti `README-CMS.txt`. Jangan pernah menaruh service_role key di frontend.
