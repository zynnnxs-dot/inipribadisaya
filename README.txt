NDREXAN WEBSITE - MINIMAL REDESIGN

Theme:
- Default: dark charcoal/black with red accents
- Toggle to light: warm white with gold accents
- Signature accent font: Caveat (Google Fonts; requires internet)

Preview locally:
1. Extract this ZIP.
2. Open index.html in a browser.
3. For best results, run a local static server from this folder, e.g. `python -m http.server 8080`, then open http://localhost:8080.

All original portfolio images and assets are retained. The ECObike preview uses an external iframe and needs internet access.
